# IMSI-free-VXP-files
IMSI free VXP Files/games for MRE capable series 30 phones.

# Why?
Many phones (like nokia 3310 2017) require an IMSI signed VXP file with your sim card. A spare sim isn't an option.
### However,
RSA signed vxp files (from mediatek) are fine, they are recognized by the firmware. So unless you are willing to edit the firmware, these vxp files are what you can run without any IMSI signing.
